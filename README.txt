KASA Woodworks - Frontend (HTML + CSS + JS)

Chalane ke liye: index.html par double-click.

Files:
- index.html   : structure
- style.css    : design
- script.js    : animations, pop-up, gallery, day/night
- images.js    : PHOTOS KA CONFIG (yahi file edit karni hai)
- images/      : yahan photos rakho
- IMAGE-NAMES.txt : saari photo file names ki list

Photo naming: kitchen-pic1.jpg, wardrobe-pic2.jpg, tvunit-pic1.jpg ...
Jo photo nahi hogi wo apne aap hide ho jayegi. Bas folder mein daalo aur refresh karo.

Colors (dark):  bg #16110e | text #efe4d6 | gold #d6b45c
